# Clash-Verge-disable-system-DNS
Prevent Clash Verge rev on macOS from modifying system DNS when TUN&amp;Fake-IP is on

Usage:
```bash
chmod +x clash-verge-disable-system-dns.sh
sudo ./clash-verge-disable-system-dns.sh install
```

If restore needed:
```bash
sudo ./clash-verge-disable-system-dns.sh restore
```
